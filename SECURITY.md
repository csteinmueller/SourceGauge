# Security Policy

## Supported versions

Only the latest released version of SourceGauge receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report privately via [GitHub Security Advisories](https://github.com/csteinmueller/SourceGauge/security/advisories/new).

Include a description, affected versions, and reproduction steps. We aim to acknowledge reports within 7 days.
